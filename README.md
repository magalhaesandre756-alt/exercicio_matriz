# Exercícios de Matriz

Repositório de exercícios em C para treinar lógica de programação, com 
foco em manipulação de matrizes (arrays bidimensionais) e laços aninhados 
(`for`).

## Conteúdo

- `exercicio_1.c` — matriz 4×4: leitura, impressão, exibição da diagonal 
  principal, cálculo do traço (soma da diagonal) e soma dos elementos 
  acima da diagonal principal.
- `exercicio2.c` — matriz 5×5: leitura, impressão e busca de um valor na 
  matriz, retornando a posição (linha e coluna) onde foi encontrado.
- `exercicio3.c` — duas matrizes 3×3: subtração entre matrizes (C = A − B) 
  e cálculo da matriz transposta do resultado.

## Tecnologias

C

## O que aprendi

Manipulação de matrizes (arrays bidimensionais) em C, uso de laços `for` 
aninhados para percorrer linhas e colunas, passagem de matrizes como 
parâmetro de função, uso de ponteiros para retornar múltiplos valores 
(linha e coluna encontrados) e operações matriciais como subtração e 
transposição.
